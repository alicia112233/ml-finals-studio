Formula Reference

Use these as active-recall targets: cover the explanation, say what every symbol means, then check the short note.

Training example
(x_n, t_n)

x is the attribute/input and t is the target. The Olympic example uses year as x and winning time as t.

Linear model
t = f(x) t = w0 + w1 x t = w^T x

w0 and w1 are parameters. Vector form keeps the model compact when there are more attributes.

Loss at one point
error_n = t_n - y_n loss_n = (t_n - y_n)^2

The notes use squared error intuition: bad predictions produce larger penalties.

Mean square error
MSE = (1/N) sum_n (t_n - y_n)^2

Average the loss over all training points to get one number to minimise.

Matrix prediction
y = Xw t_new = X_new w

X stacks the input rows. A new row X_new gives a new prediction after multiplying by w.

Parameter solution
w = inv(X.T @ X) @ X.T @ t

This is the Python expression from the notes for fitting the linear regression parameters.

Additive noise
t_n = w^T x_n + epsilon_n epsilon ~ random variable

Noise represents unpredictable error. Modelling it helps describe confidence.

Discrete probability
P(X = x) sum_x P(X = x) = 1

Use for countable outcomes such as coin tosses, dice rolls, or number of emails.

Continuous density
p(x) P(a <= X <= b) = area under p(x)

Densities are not probabilities. Probabilities come from ranges/areas.

Joint and independence
P(X = x, Y = y) Independent: P(X,Y) = P(X)P(Y)

If one outcome does not depend on the other, the variables are independent.

Conditioning
P(X = x | Y = y) p(t_n | x_n, w)

Conditioning means probability or density given known information.

Likelihood
L(w, sigma^2) = p(t | X, w, sigma^2)

Likelihood evaluates how well parameters explain fixed observed data. For continuous variables, it is not a probability.

Perceptron score
z = w^T x + b y = activation(z)

A perceptron computes a weighted sum plus bias, then applies an activation.

Activation functions
sigmoid(z): 0 to 1 tanh(z): -1 to 1 ReLU(z): max(0, z)

The notes list sigmoid, hyperbolic tangent, and ReLU for non-linear behaviour.

Network losses
MSE: regression-style error Cross-entropy: classification error

The ANN training notes mention MSE and cross-entropy before backpropagation.

Gradient descent
Minimise J(w) w <- w - learning_rate * gradient

Use gradients to update weights so the cost/loss decreases.

K-fold cross-validation
K = 4: train on 3 folds, test on 1 fold repeat 4 runs

Use the mean and variance of performance to compare hyperparameters.

CNN output size
32x32x3 image 3x3x3 filter -> 30x30x1 map 30 x 30 = 900 neurons

This is the convolution example from the notes. Padding can keep output size the same.

RNN hidden state
h(t) = memory at sequence step t activation = ReLU, tanh, or sigmoid

RNN output uses memory from previous sequence steps plus the current input.

LSTM gates
forget gate: keep/discard C(t-1) input gate: candidate update output gate: expose useful state

LSTMs are RNNs with gates that manage what information is remembered.
